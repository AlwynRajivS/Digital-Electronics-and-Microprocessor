🔗 Links

🎥 YouTube instructions

  1. Record a 3–5 minute screen demo showing your working project end-to-end.
  2. Upload it to YouTube as Unlisted (not Private) so evaluators can open the link.
  3. Title format: ProjectID - Project Title - Register Number
  4. Paste the shareable link (youtu.be or youtube.com/watch) above.

🐙 GitHub instructions

  1. Push your complete, working source code to a public GitHub repository.
  2. Include a README.md with setup steps and a short project description.
  3. Commit history should reflect genuine incremental work, not a single upload.
  4. Paste the repository link above (e.g. https://github.com/you/project-name).

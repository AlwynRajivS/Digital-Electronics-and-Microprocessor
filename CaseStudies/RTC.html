Learn Each Module

① Clock Divider

100M → 1

A 26-bit counter counts from 0 to 49,999,999. The output clock toggles each time the terminal count is reached. Two toggles form one complete 1-second period.

② MOD-60 Counter

0 → 59

Used twice: once for seconds and once for minutes. When enabled and the count reaches 59, the next event returns it to zero and asserts a carry pulse.

③ MOD-24 Counter

0 → 23

The hours counter increments after a complete 59:59 rollover. After 23 hours, the next increment wraps to 00 for a 24-hour clock.

④ Decimal Digit Conversion

Each time value is separated into tens and ones using division and modulo operations: hours / 10, hours % 10, etc. These six digits drive six 7-segment decoder instances.

⑤ 7-Segment Decoder

A combinational case statement maps decimal digits 0–9 to segments a–g. The live red display above demonstrates the same mapping visually.

Simulation Process

  1. Generate a clock in the testbench using always #5 clk = ~clk;.
  2. Assert reset to initialize hours, minutes and seconds to zero.
  3. For practical RTL simulation, bypass waiting for 100 million physical input cycles or test the divider separately with a reduced parameter.
  4. Verify seconds count 0–59 and generate a one-cycle carry.
  5. Verify the seconds carry enables the minute counter.
  6. Verify minute rollover enables the hour counter.
  7. Confirm 23:59:59 transitions to 00:00:00.

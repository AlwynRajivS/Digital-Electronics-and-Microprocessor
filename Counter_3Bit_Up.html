07 · Minimisation

Karnaugh maps for JA, KA, JB, KB, JC, KC

Six 3-variable maps (QC, QB, QA). Small digits in each cell are the minterm number. In every map, the winning loop is drawn with a solid outline; the column-header digits that stay fixed across that loop are highlighted — those are exactly the variables that survive in the final equation. A short explanation under each map spells out the "why."

08 · Implementation

Logic diagram

Built from two 74LS76 dual JK flip-flop packages and one 74LS08 AND gate — matching a real hardware wiring diagram, pin numbers included. PR̄ is tied to Logic 1 (preset disabled) on every flip-flop; CLR̄ is a common active-low clear bus; CLK is shared by all three stages. JA=KA=1, JB=KB=QA, JC=KC=QAQB. The Q outputs light up live for the current state.
